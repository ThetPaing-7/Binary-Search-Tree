# Binary Search Tree

A JavaScript implementation of a Binary Search Tree (BST).

## Features

- Build a balanced BST from an array
- Insert nodes
- Delete nodes
- Search for values
- Find node height
- Find node depth
- Check if the tree is balanced
- Level-order traversal
- Depth-first traversals

## What I Learned

- Binary Search Tree concepts
- Tree traversal
- Queue-based level-order traversal
- Node references and pointers
